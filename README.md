# meu-portfolio
Este projeto e protótipo de portfólio profissional desenvolvido para apresentar minha formação acadêmica, habilidades, objetivos profissionais e projetos desenvolvidos na área de tecnologia.  O protótipo foi desenvolvido inicialmente no Figma, utilizando uma estrutura simples e organizada para facilitar a navegação e apresentação das informações.
